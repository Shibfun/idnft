Woofswap - User Guide

1. Preparation

  • Ensure MetaMask is installed and connected to the Shibarium network (Chain ID: 109).
  • Prepare BONE tokens on Shibarium for gas fees.

2. Connect Wallet

  • Click the “Connect Wallet” button at the top of the page.
  • Authorize the connection in MetaMask; the page will display your wallet address (e.g., “Connected: 0x123...456”).
  • Confirm the network status shows “Connected to Shibarium”.

3. Create an NFT Contract

  • In the “Create New NFT Contract” section, enter the following:
    • Suffix: NFT suffix (e.g., “damn”), alphanumeric only.
    • Payment Token Address: Payment token address (use “0x0000000000000000000000000000000000000000” for no token payment).
    • Payment Amount: Payment amount in tokens (e.g., “0” for free).
  • Click “Create NFT Contract” and confirm the transaction in MetaMask.
  • Upon success, the “Your Created NFT Contracts (Latest 10)” section will display the new contract address (e.g., “Suffix: damn (0x123...456)”).

4. Mint an NFT

  • In the “Mint NFT” section, enter the following:
    • NFT Contract Address: Copy a contract address from “Your Created NFT Contracts” and paste it here.
    • After entering the address, contract info (e.g., “Suffix: damn”) will be displayed; confirm the suffix is correct.
    • NFT ID: Unique ID for the NFT (e.g., “xxx”), alphanumeric only.
  • Click “Mint NFT”; the frontend will check if the NFT ID already exists:
    • If it exists, you’ll see “This NFT ID is already minted”.
    • If not, the minting process will proceed.
  • If token payment is required, the button will show “Approving...” and “Minting...”; confirm the transaction in MetaMask.
  • Upon success, the status will show “NFT minted successfully!”.

5. View NFT Preview

  • After minting, the “NFT Preview” section will display the NFT’s SVG image (dark gray background with light gray text).

6. Notes

  • Ensure the network is Shibarium (Chain ID: 109), or interaction will fail.
  • If contract info doesn’t display, verify the address was created by “0x91795A1c17D96591aA8F96CB66973E27a272459d”.
  • Confirm the “Suffix” before minting to avoid mistakes.
  • If errors occur, open the browser console (F12) to view logs and contact support.
